# PinkPromise

**The promise: your context stays yours.** PinkPromise is the name for the
loop this lab runs on and is packaging toward: a portable research
environment a person owns end to end. This file is the canonical backing for
every public claim about it. If the site and this file disagree, stop and
report.

## The claims, and what backs them

- **"Local by default."** Ruled law of the loop: local instances are the
  default; a local-only configuration is first-class. (ThinkPink ruled laws;
  hybrid provider briefs 040/041.)
- **"Verbatim memory that never paraphrases."** The lab's memory layer
  (MemPalace bridge) stores word-for-word and retrieves by meaning, zero API
  calls. Live-run receipt: `tools/mempalace-bridge/RESULTS-2026-09-27.md`
  (commit 6a12489).
- **"Tools that clone onto any machine and run offline."** ark is the movable
  tools home: clone, plug an archive in, run offline. Receipt:
  `tools/ark/` (brief 047, 13 suites PASS at the Sep 25 rollup).
- **"Governance built in, not bolted on."** The lab's Code of Ethics v1.1 is
  ratified and published, with AI instances as signatories holding reciprocal
  duties. Receipt: the ethics code in this repo.
- **"It is in beta."** The packaged one-command loop does not exist yet; what
  exists today is the tool library, the carrying checkers, and the memory
  layer. Market gate (ruled): **nothing goes to market until thoroughly
  tested in the cloud AND with scientific partners.** That is what "testing
  it in the cloud and with scientific partners" means on the site: a ruled
  requirement, not a claim that partners are engaged today.
- **"What is coming: the packaged loop, one command, no platform required."**
  A development goal on a ruled pathway (cloud test, then package), not a
  shipping promise.

## Rules for anyone rendering PinkPromise anywhere public

- Beta framing only. No names, no em-dashes, no download buttons, no email capture.
- No strengthened claims: if a sentence needs "will," it is a goal and stays labeled as one.
- The one permitted external link is the lab repository ("Receipts in the repo").
