# RESULTS -- MemPalace bridge live run, 2026-09-27

Environment: Vellum assistant sandbox, Debian-class Linux, Python 3.13.5, PyPI direct.
Installed: `mempalace` 3.10.0 (MIT). No API keys used anywhere in the run.

## Run log

1. **Install.** `pip install mempalace` pulled the full stack: ChromaDB 1.5.9,
   ONNX Runtime 1.30.0, tokenizers, numpy path, MCP server entry point
   (`mempalace-light-mcp`). Three transitive wheels (`pyyaml`, `typing_extensions`,
   `numpy`) were missing from the wheel's metadata on Python 3.13 and had to be
   installed into MemPalace's own site-packages; its startup deliberately strips
   `PYTHONPATH` (ABI guard, upstream #2484), so env-var workarounds are ignored
   by design. The console script's shebang also resolved to a different
   interpreter than the one holding the deps; invoking it through the owning
   `python3` fixed that. All three frictions are handled in
   [mempalace-fold-in.sh](mempalace-fold-in.sh).
2. **Palace init** on the lab root, non-interactive (`--yes --no-llm`):
   **24 rooms auto-detected** from repo structure (harness, briefs, papers,
   ark, rainbow-rock, etc.). Zero LLM calls.
3. **Mine.** 85 files → **667 drawers filed**, single room (`general`) for the
   flat wiki corpus. First-use embedding model (~80 MB MiniLM) downloaded once,
   then fully offline.
4. **Smoke search (the honest test).**

   Query: *"why do local models summarize the kernel instead of enacting it"*

   ```
   [1] concepts / general
       Source: address-frame-hypothesis.md
       Match:  cosine_sim=0.349  bm25=2.365

       ...The address FRAME, not the kernel content, decides whether a model
       enacts the carry or comments on it.
   ```

   **PASS.** The top hit was the page that actually answers the question,
   returned verbatim, hybrid-scored (semantic + lexical). No paraphrase,
   no API call, nothing left the machine.

## Findings for the loop

- Retrieval quality on a small, dense, interlinked markdown corpus is strong
  out of the box. The lab's record is exactly this shape.
- The palace DB is self-contained; point it at a persistent volume and it
  survives moves. Docker image is multi-arch (runs on Apple Silicon), which
  fits the Mini lane.
- **Privacy:** the auto room-map will index anything it finds, including
  `source-material/`. The fold-in script refuses that path by default and
  mines only the safe layers. See README privacy law.
- Verbatim storage matches the lab's own carried-context finding
  (Loci A/B, Sep 25): the index organizes; it never paraphrases.
