# cleanroom; cold vs warm context sizing (White Cat)

Part of the ThreadCat lab tooling. Free, local, stdlib-only Python.

## Status: SCAFFOLD, PENDING TESTING

Sizes the carried text of runs in a lab `timeline.jsonl` and reports
per-run event counts and rough token estimates (~4 chars/token, an
estimate and labeled as one). The cold-vs-warm comparison itself is a
human step; the tool prints the instruction. Not yet validated against
the full timeline; treat numbers as inputs, not findings.
