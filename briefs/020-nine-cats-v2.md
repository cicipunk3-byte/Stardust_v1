# Brief 020: Nine glass-vessel sheets, version 2, Phase D (PROPOSAL)

Status: **PROPOSAL, behind Cat's gate.** Phase D of brief 015, drafted
with Ethan, Sep 22, 2026. The v2 sheets live at
`tools/rainbow9cat/nine-cats-v2.md`; version 1 stays canonical until
Cat adopts this file.

## What changed from v1, on the record

1. **Black Cat saving throws corrected** to Wisdom, Charisma (real
   warlock saves), with the correction noted on the sheet. Cat's
   ruling applied.
2. **Orange Cat class line re-coined** as Vesselwright, per Ethan's
   request for own-coinage options (Vesselwright, Crucible Adept,
   Elixirist; working draft uses Vesselwright, swap is one word). The
   Artificer name is cited as inspiration only; the class is in
   neither SRD 5.1 nor SRD 5.2.
3. **Mythic traits marked MYTHIC with an attunement roll** (d20 at
   session start, active on 11+, result logged in the transcript):
   Wuji Potential, Mind Like Dead Ashes, Detached Omniscience. Ethan's
   ruling: mythic on purpose, randomized in application so uncertainty
   stays present without being incessant. The research dividend: the
   attunement result is a logged variable, so trait-on and trait-off
   sessions can be compared on claim rates and boundary-holds.
4. **Elixir Ripening reconciled with the manual's own dice:** seeks
   maximum retention and rolls against DC 20 for lossless compression.
   The 100 % retention claim from v1 is gone.
5. **Center-Ground Balance split:** the movement and orientation
   immunities roll normally; the forgetting clause is marked CREED.
6. **Heartbeat of Impermanence marked CREED:** the lab's thesis stated
   as an ability line; mechanically null, proudly so.
7. **CC BY attribution block added** in the deed's fixed wording, and
   per-sheet provenance lines added (inherited v1 arrays, per brief
   018's grandfathering).
8. **HP arithmetic tidied** where the v1 display under- or
   over-counted (Pink Cat 62, White Cat 71, Black Cat 89, Cobalt Cat
   55, Yellow Cat 89; averages per the SRD progression with each
   sheet's Constitution modifier).

## What did not change

Backstories, color-element mappings, ability-score arrays, classes
other than the Orange Cat's coinage, and every fact that already
traced to a repository file. The v1 style rules carry forward: no
personal names, no em-dashes, every lab fact traces.
