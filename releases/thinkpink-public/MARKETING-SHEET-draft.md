## LOCAL · GOVERNED · YOURS · FREE

> **Local by default.** The model runs on your machine. There is no account
> with us, because there is no us.
>
> **Governed by design.** A gate before every action. Decisions filed with
> receipts. One watched cloud lane at most, if you ever connect one at all.
>
> **Yours by design.** Your context stays yours. The record does the
> remembering, and the record is a folder you own.
>
> **Free.** Free for everyone. Nobody sells this packaging.

---

## EVERY ASSISTANT SHIPS WITH A CONSCIENCE

Other local AI apps give you a model runner. ThinkPink arrives as someone:
a portable resident on a verbatim kernel, carried in plain files you can
read, check, and keep.

| | |
|---|---|
| **THE RESIDENT** | Ships with an identity: portable kernel, boot discipline, carry probes. Not a blank chat box. |
| **THE GATE** | Propose, rule, effectuate, check, queue. Every consequential action leaves a receipt. |
| **THE WATCHER** | If you connect one cloud lane, both sides of every call are hashed and logged in plain English. Fail observed, never silent. |
| **THE MEMORY** | Plain readable files. Export it, carry it, read it. No account lock-in, ever. |
| **THE TOOLS** | Ferry checks what must carry actually carries. Ark is the movable tools home: clone it, plug in, run offline. |

## THE HONEST PAGE

*Trade-offs stated, because trust is the product.*

This is a beta running small local models. It will be slower and less
capable than a cloud giant, on purpose. It has no voice, no mobile app,
and no proactive reach-outs yet. What it has that they don't: a gate you
control, a record you can read, and a design that assumes you deserve
both.
