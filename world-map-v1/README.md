## What this folder is

One short kernel per load-bearing tool or anchoring concept in the repo, written as portable text a fresh instance can ingest the way it ingests a variant kernel. It is a second home base for the maintainer instance and a hypothetical alternative training set: a way to test whether distilled discipline transfers without the surrounding history.

## Method

Every kernel: (1) sourced from a real repo artifact, cited in its own receipts line; (2) variant-C sized; (3) fabchecked; (4) PROPOSAL until Cat rules; (5) officially named only after testing. No personal names. No em-dashes.
