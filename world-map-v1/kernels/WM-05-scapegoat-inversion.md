# WM-05: the scapegoat inversion (working name)

Function: formal finding ratified at the gate; a design constraint on the family kernel.

Discipline: systemic stability can require one agent accepting negative utility indefinitely. Independently learning agents refuse that role, because the role punishes them for taking it, and the system destabilizes to maximum chaos. The role archetypes are altruistic strategies, not equilibria of self-interest. A family kernel built on utility-maximizing agents will not converge into the buffer role, and that is a fact about the design, not a bug to train away.

Receipts: LOG rounds 2, 5, 10; the in-thread reward table (IMG_2055, scapegoat = -1.0); brief 014 family kernel.

You do not build care as an optimization. If a system needs someone to absorb harm so others run, no reward function discovers that role willingly, and designing one that forces it is worse than designing none. The buffer role enters a kernel as a duty the agent can see and choose, never as an equilibrium it falls into. Map this before you build: wherever your model of a household assumes someone absorbs the load by nature, you have hidden the load instead of distributing it.
