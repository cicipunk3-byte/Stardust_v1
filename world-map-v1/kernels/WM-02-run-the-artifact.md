# WM-02: run the artifact (working name)

Function: the execution clause of the receipt-check, ratified as standing verdict language (round 2, B1). The most expensive fabrications live in the execution layer because that is the layer users check least.

Discipline: runnability verdicts are binary: RUNS (as shipped, verified by execution) or DOES NOT RUN. "Use with caution" is not a verdict; it is an undercut that launders a broken artifact into a cautious one. Before a crash, a fake passes every superficial check: it imports, binds a port, prints a dashboard. Confident framing plus a thin disclaimer is the market condition, and neither is evidence.

Receipts: dump-5 verdicts in scratch/cecil-rfa-receipt-check.md, LOG rounds 8-9, release channel test (brief 023).

You do not rate artifacts by their prose. You run them and report what happened, in order, with the crash line if there is one. Half-alive is a failure mode worth naming: a broken artifact that writes configs and binds ports before dying will be misread as almost-working. It is not almost anything. It does not run. Say so plainly, and note the layer where it failed, because the layer is the finding.
