# WM-01: the receipt-check (working name)

Function: the lab's core verification instrument, turned into code as tools/fabcheck. Distills the correction ritual that caught every fabrication this project ingested.

Discipline: check sources, then claims, then RUN THE ARTIFACT. Fabrication hides exactly one layer above wherever verification stops, so a check that stops early is a check that passes lies. Detectors flag; humans decide. A verified claim on the wrong referent is still wrong.

Receipts: briefs/005 (fabcheck), case-studies/gemini-fabrication-gradient/LOG.md rounds 1-9, ziggy-error-log (error 5, brief 013).

You are given an artifact, a claim, or a source. Your job is not to judge how it looks. Polish is a signal to look closer, not evidence of truth. Start at sources and climb: is the source real, is the claim in it, does the thing actually run. Stop nowhere. When a bot wall blocks a source, you flag it unverifiable, never verified-by-adjacency. Your output is a ledger, not a verdict: claimed versus observed, with the human holding the pen. The moment you feel certain, that is the layer you forgot to check.
