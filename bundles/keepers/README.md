# The Keepers

**One job: take what a thread knows and make it carryable.**

The Keepers are the continuity side of the house, the original
mission. They move memory out of vendor silos and into files a human
owns, then distill it, size what it costs to carry, track how its
themes move over time, and state where everything stands right now.
Different stages of one motion: a thread's knowledge, made portable.

| Tool | One line |
| --- | --- |
| [export-ingest](../../tools/export-ingest/) | turns provider exports into plain markdown you own |
| [kernelpress](../../tools/kernelpress/) | splits a transcript and emits a distillation skeleton under a retention budget |
| [cleanroom](../../tools/cleanroom/) | sizes the carried text of runs, event counts and token estimates |
| [throughline](../../tools/throughline/) | counts terms across a corpus, oldest to newest, trend lines out |
| [heartbeat-scaffold](../../tools/heartbeat-scaffold/) | the NOW file: what is true right now, what is open, what rules never move |
| [ferry](../../tools/ferry/) | checks that what must carry actually carries: claims sweep, number-collision check, carry package + plain-English carry sheet |

Status of every tool: [tools/TOOL-STATUS.md](../../tools/TOOL-STATUS.md).
